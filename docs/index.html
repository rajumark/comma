Why Comma

Readable text, without the cloud

No server, no API key, no per-request bill. A small Kotlin library that you can read, test and ship.

Made for Indian text

Hinglish and Tanglish chat, and Hindi, Bengali, Marathi, Gujarati, Punjabi, Tamil, Telugu, Kannada, Malayalam and Urdu in their own scripts, plus English and six European languages.

The right marks

A full stop is । in Hindi, Marathi, Bengali and Punjabi and ۔ in Urdu, where questions end in ؟. Capitals for sentence starts, names and acronyms like NASA.

No dependencies

Pure Kotlin inference. There is no ONNX Runtime, TFLite, ML Kit or native code, and it works from minSdk 21 in Kotlin or Java.

Private & offline

The model ships inside the AAR. It makes no network calls, needs no permissions and sends no telemetry, so what people dictate never leaves the phone.

Add it to your build

One line in your Gradle file, available now via JitPack. No API key, no account.

JitPack live

dependencyResolutionManagement {
    repositories {
        mavenCentral()

    implementation("com.github.rajumark:comma:v1.0.0")

Usage

One call per message

Load once and reuse the instance. restore() is thread-safe.

Kotlin
val comma = Comma(context)

comma.restore("where are you we are all waiting outside")
// "Where are you? We are all waiting outside."

comma.restore("آپ کیسے ہیں میں ٹھیک ہوں")
// "آپ کیسے ہیں؟ میں ٹھیک ہوں۔"

comma.close()
Java
try (Comma comma = new Comma(context)) {
    String text = comma.restore(
        "can you pick up the kids at 5 i am stuck in a meeting");
}

FAQ

Questions

What is Comma?

An Android library that adds punctuation and capitals to text that has none, like voice typing, speech-to-text output or fast-typed chat.

Which languages does it support?

English, Hinglish and Tanglish, Hindi, Bengali, Marathi, Gujarati, Punjabi, Tamil, Telugu, Kannada, Malayalam and Urdu, plus Spanish, French, German, Portuguese, Italian, Russian and Indonesian. Chinese, Japanese and Thai are not supported, because they don't put spaces between words. To detect the language first, use Beacon.

What if my text already has some punctuation?

Comma removes the marks it predicts (commas, full stops, question and exclamation marks) and adds its own, and re-cases the text. Other characters like apostrophes, numbers, emails and links are kept.

How long can the text be?

Any length. Long text is cut into overlapping windows, so every word is judged with context on both sides.

Does it run on device?

Yes. Inference runs entirely on the device in plain Kotlin. It makes no server calls, needs no network permission and sends no telemetry.

Is the Kotlin port exact?

Token ids, every word's label and the restored text match the reference implementation on all 94 test vectors, both on the JVM and on an Android device.

How much does Comma cost?

Nothing for products with up to 10,000 monthly active devices per platform, including commercial apps. There is no API key or account, and no limit on how often it runs. Above that, a commercial license is needed; see Pricing.
